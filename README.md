# Virtual Wardrobe (MVP)

Цифровий гардероб та інтелектуальний підбір аутфітів.

Детальний опис вимог, архітектури та алгоритмів дивіться у [docs/TZ.md](docs/TZ.md).

## Структура репозиторію
- `apps/api` — ASP.NET Core Web API (.NET)
- `apps/web` — React SPA (Vite + TypeScript)
- `packages/` — спільні типи, клієнт API та конфігурації
- `infra/` — Docker Compose конфігурації для локального запуску
- `docs/` — специфікація (ТЗ) та архітектурні рішення (ADR)
